# 为图集作画：速写指南

[English](sketch-guide.md)

本图集有约六百幅速写：旅程沿途的场景、各个时期的城市、发明、地标和自然奇观。它们是人们记住这部图集的原因之一，也是错误最容易藏身的地方之一。本指南写给想要修正、建议或绘制速写的人：速写是什么、应该是什么样子、如何把历史画对，以及如何提交。

关于技术细节（API 密钥、生成脚本、完整的文件结构），请看[图像生成指南](image-api-guide.md)（英文）。本指南只谈画本身。

## 一、速写是什么

每一幅速写都是**想象插图**：一页从未真正在现场画下的野外速写本，依据有出处的文字描述，画出当时那里的样子。卡片上总会注明（“想象速写 · 据普罗科匹厄斯……”）。速写从不冒充当时的艺术品、照片，或确知无误的复原图。

由此有两点：

- **文字在先。** 说明文字和出处才是事实，图画随之而来。图画不能添加说明文字所不支持的事实；一幅美丽却有错误细节的画，就是一幅错画。
- **坦承推测。** 证据不足之处（已毁的奇观、失落城市的天际线），速写是一种诠释，说明文字要如实说明。

## 二、画面风格

所有速写都属于同一套笔记本，取法十八、十九世纪探险队画家的笔意：库克航行的随船画家、“小猎犬号”上的康拉德·马滕斯、随利文斯通出行的托马斯·贝恩斯。每一页都有：

- **横幅，3:2。**
- **铅笔底稿**，保留构图辅助线。
- **快速的棕褐色墨线**覆盖其中一部分，用松散的平行排线表现阴影。
- **几层不均匀的水彩**：赭石、灰绿与褪色的蓝（旅程可略加一点红），颜料积聚，有些地方留出纸色。
- **未完成的边缘：** 细节集中在主体上，天空、页边和近景渐渐消融在略有霉斑的米色纸上。
- **完全没有文字：** 没有标注、说明、日期、数字或签名。画中若有铭文，只是无法辨认的笔迹。
- **没有边框、装订或画框。** 只是一页。
- **是工作中的速写，** 不是完成的油画、照片、数字渲染、概念设计图或信息图。

每一类题材另有规则。所有模型提示词开头所用的确切文字，见 [`data/depictions/style.json`](../data/depictions/style.json)。

| 类别 | 画面内容 | 特别规则 |
| --- | --- | --- |
| **城市** | 城市的同一个固定视角，每个时期重画一次 | 每个时期都从 `view` 写明的同一地点画出，随年代切换时画面对齐 |
| **旅程** | 某一站的某一刻，近到能看清面孔、双手、工具和货物 | 旅行者始终是同一个人，处在动作之中，绝不立正摆拍；有些页面只画队伍所见；场景旁可附一个物件或动物的小幅细部 |
| **发明** | 器物本身、作坊，或使用它的人 | 只有一个连贯的场景，最多附一个不加标注的小细部 |
| **人造地标** | 有明确年代的建筑写生 | 单一透视，结构与比例可信；人物可有可无且要小；不画现代旅游设施 |
| **自然奇观** | 真实的地貌 | 真实的地形与尺度，单一视点；不画旅游设施、不虚构地物、不画摆姿势的探险者 |

## 三、把历史画对

大部分功夫在下笔之前的考证。

1. **确定年份。** 一幅速写只画一个时刻：城市某个时期之初、旅程某一站的那一天、地标在某个注明的年份。把年份写下来。
2. **列出当时已有和尚未出现的东西。** 建筑、城墙、桥梁、港口、海岸线的形状。最常见的错误是画进了后来的地标：1453年以前圣索菲亚的宣礼塔、帖木儿时代撒马尔罕的雷吉斯坦广场、葡萄牙人建堡之前基尔瓦的堡垒、青铜时代小岛上的哥特城堡。
3. **核对人们用的东西：** 船只（三列桨战船不是加莱桨帆船，卡拉维尔帆船也不是盖伦帆船）、服饰、工具、牲畜、作物、钱币和兵器，都要合乎当地当时。
4. **尊重地描绘人物。** 当地的人，穿当时的衣服，做当时的事，绝不是围绕来访英雄的异域点缀。
5. **标明不确定之处。** 如果证据没有说明某物的样子，就选择最朴素、最合理的形态，并在说明文字中说明这是复原。

好的依据包括遗址发掘报告和考古调查、当时的描述（旅行者本人对这座城市的记述）、当时的地图与城市图，以及博物馆的器物图录。图像，包括遗址照片和后世绘画，只能作为事实的证据，绝不能照着临摹。

## 四、文字：说明与记录

每幅速写在其题材的 `subject.json` 中有一个条目（全部字段见[图像生成指南第三节](image-api-guide.md#3-how-the-data-fits-together)）。贡献者需要写的有：

- **`title`：** 这一页的简短名称（“奥斯曼时代的伊斯坦布尔”“贝勒里昂的锡贸易”）。
- **`caption`：** 一到三句平实的话，用第三人称说明画面内容，不加渲染，并点明不确定之处。
- **`sources`、`confidence`：** [`data/sources.csv`](../data/sources.csv) 中的出处 id（新出处请先加入其中），以及 `high`、`medium` 或 `low`。
- **`prompt`：** 这一页要画什么：年份、视角、哪里有什么、人物在做什么，以及不要画什么。
- **`evidence`**（可选，但欢迎）：一个链接，加一句话说明画面依据。

中文标题与说明写在 [`data/i18n/zh/depictions.json`](../data/i18n/zh/depictions.json)；不会写也没关系，会有人补上。

## 五、作画

### 用图像模型

目前大多数速写由图像模型生成。好画面来自好提示词，也来自耐心：

- **从风格出发。** 提示词由 `style.json` 中该类别的风格文字，加上这一页自己的 `prompt` 组成。不要改写风格文字，整套图应像出自一人之手。
- **写得具体。** 说出地标的名字和它在画面中的位置（“圆顶在左侧偏中，港口堤岸向右延伸”）。写明不要画什么（“没有宣礼塔”“岛上没有石头城堡”）。
- **保持连贯。** 城市较晚的时期以较早的画面为底图修改（`base`）；旅程各场景以第一个场景为参考，保持旅行者的面孔（`ref`）。每个场景都重复旅行者的外貌描述。
- **多画几张，只留一张。** 生成几张候选，用下面的检查表逐一判断。如果某一页屡屡失败，就改进提示词，而不是将就一张差不多的。
- **记下一切。** 完整的提示词、模型和日期写进这一页的 `.json` 记录，任何人都能看到它是怎么画出来的，也能重画。

如果您有 API 密钥，[`scripts/generate_images.py`](../scripts/generate_images.py) 会替您拼接提示词并做记录，用法见[图像生成指南](image-api-guide.md#4-workflow-for-one-subject)。没有也没关系，把您用的提示词和画一并发来，记录会有人替您写好。

### 手绘

欢迎手绘作品，卡片上会署上画者的名字（“想象速写，某某绘”）。它们应能自然地与其他速写并列：米色纸上的铅笔、墨线和少许水彩，边缘未完成，没有文字。在开始画一组之前，请先到[讨论区](https://github.com/Greenere/the-world-we-know/discussions)说一声，以便统筹安排。

- 在均匀的日光下把画页**平整地扫描或拍摄**，宽度至少 **1536 像素**，裁成 3:2。
- **发送原始文件**（PNG 或高质量 JPEG）；较小的尺寸由构建自动生成。
- **记录**中以 `artist` 写上您的名字，取代模型，并照样附上说明、出处和画面依据。

## 六、检查表

每一项的答案都是“是”，这一页才会被采用。

- [ ] **历史：** 画中一切在那一年、那个地方都确实存在，没有不存在的东西。
- [ ] **说明：** 画面所示与说明文字一致，不多出说明不支持的内容。
- [ ] **人物：** 合乎当地当时，描绘得有尊重。
- [ ] **没有文字：** 任何地方都没有字母、数字、标注或签名，天空和页边也不例外。
- [ ] **风格：** 米色纸上的铅笔、墨线和淡彩，边缘未完成，单独一页；不是油画、渲染或照片。
- [ ] **视角：** 城市与其他时期同一视角；旅程与其他场景是同一位旅行者。
- [ ] **记录：** 给出出处与可信度，并记下提示词和模型（或画者）。
- [ ] **权利：** 是您自己画的，或您有权以 CC BY 4.0 共享，且没有照搬现有的艺术作品。

## 七、修正速写

如果某幅速写画错了，**请使用其卡片上的“提出更正”。** 表单已经写明正在显示的是哪一幅速写，以及它的提示词和出处记录在哪里。请说明哪里有误（“这些船是十七世纪的盖伦帆船；1100年应是德罗蒙战船”），以及您的出处显示的应是什么样子。

修正通常意味着改进提示词、重画这一页。旧画会保留在仓库的历史中。

## 八、提交

- **建议题材、修正画面或发送作品：** 请使用[速写表单](https://github.com/Greenere/the-world-we-know/issues/new?template=sketch.yml)。把图片拖进表单即可附上。
- **如果您使用 git：** 把图片以 `<id>.webp`（或 `.png`）、记录以 `<id>.json` 放进 `data/depictions/<类别>/<题材>/`，在 `subject.json` 中新增或更新条目，运行 `npm run data`，再提交拉取请求。参见 [CONTRIBUTING.zh.md](../CONTRIBUTING.zh.md#自己修改数据)。

速写与图集的其他内容一样，以 [CC BY 4.0](../data/LICENSE.md) 发布。
